# 🎬 CineSearch

O **CineSearch** é uma aplicação web para busca e descoberta de filmes, desenvolvida como projeto acadêmico do curso de **Análise e Desenvolvimento de Sistemas**.

A aplicação permite pesquisar filmes e visualizar informações sobre os títulos encontrados. O projeto também foi desenvolvido como **Progressive Web App (PWA)**, permitindo sua instalação em dispositivos móveis.

## 🚀 Demonstração

🌐 **Acesse o CineSearch:**
https://gaahtenorio.github.io/cine-search/

💻 **Repositório:**

## 📱 Progressive Web App

O CineSearch possui recursos de **PWA**, permitindo que a aplicação seja instalada no celular e utilizada de forma semelhante a um aplicativo.

### Recursos do PWA

* 📲 Instalação no dispositivo
* 📱 Interface responsiva
* ⚡ Service Worker
* 📦 Web App Manifest
* 📴 Cache para recursos da aplicação
* 🎨 Ícone personalizado
* 📱 Experiência adaptada para dispositivos móveis

## 🔎 Funcionalidades

* Pesquisa de filmes
* Exibição dos resultados encontrados
* Visualização de informações dos filmes
* Interface responsiva para computadores e celulares
* Instalação como aplicativo
* Funcionamento através do GitHub Pages

## 🛠️ Tecnologias utilizadas

* **HTML5**
* **CSS3**
* **JavaScript**
* **API de filmes**
* **Web App Manifest**
* **Service Worker**
* **GitHub Pages**

## 📲 Como instalar

1. Acesse o [CineSearch](https://gaahtenorio.github.io/cine-search/) pelo navegador do celular.
2. Abra o menu do navegador.
3. Selecione **Instalar aplicativo** ou **Adicionar à tela inicial**.
4. Confirme a instalação.
5. O CineSearch ficará disponível como aplicativo no dispositivo.

## 💻 Como executar localmente

Clone o repositório:

```bash
git clone https://github.com/gaahtenorio/cine-search.git
```

Entre na pasta:

```bash
cd cine-search
```

Abra o projeto no **Visual Studio Code** e execute utilizando uma extensão como o **Live Server**.
